# Screenshots

The main `README.md` references screenshots from this folder. To
regenerate them:

1. Drop the theme into a vault (`<vault>/.obsidian/themes/Artificer/`).
2. Enable it via **Settings → Appearance → Themes**.
3. Capture the following at **1920 × 1200** (or as close as your display
   allows — Obsidian's screenshot tool is `Cmd/Ctrl + Shift + 4` on most
   systems, or use the built-in command `Take a screenshot`).

| Filename | What to capture | Mode |
|---|---|---|
| `01-dark.png` | A note open with frontmatter visible, the file tree on the left, the graph view on the right | Dark |
| `02-cream.png` | Same layout as 01, in cream mode | Light |
| `03-callouts.png` | A note showing 4-6 different callout types stacked | Dark |
| `04-code.png` | A code block (JS or TS preferred) with the line-numbers Style Settings toggle on | Dark |
| `05-kanban.png` | A Kanban board with 3+ lanes and a few cards | Dark |
| `06-style-settings.png` | The Style Settings panel scrolled to show the Accent colors section | Dark |
| `07-palette.png` | The command palette open over a note | Dark |

After dropping the captures in here, commit and the README images
should render on GitHub.
