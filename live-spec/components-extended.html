The Workstream-E mints: the option-popover keystone and what it unlocks, plus pagination, the persistent banner, and the tree. Built from existing tokens — no carves.

Option-popover — .menu / .listbox

The ONE floating option list. .menu = actions (role=menu); .listbox = selection (role=listbox + aria-selected). Both use __option rows. The keyboard cursor and hover are one visual (.is-active). Drop inside .popover to float it.

Command palette

The signature tool surface — a recipe, not a new primitive: .palette = a .palette__search header (a combobox input) + the .listbox body, focus-trapped (ArtificerFocus.trap, Esc to close) on a .scrim. Opens on ⌘K.

<div class="palette" role="dialog" aria-label="Command palette">
  <div class="palette__search">
    <input role="combobox" aria-controls="list" aria-expanded="true"
           aria-autocomplete="list" aria-activedescendant="opt-new">
  </div>
  <ul class="listbox" role="listbox" id="list"> … </ul>
</div>  // const trap = ArtificerFocus.trap(el, { onEscape: close });

Pagination

Bounded, jumpable ranges. Mono/tabular numbers; current page is the one accent marker (aria-current="page"); prev/next disable at the ends. Unbounded sets → "load more" instead.

Tree view

Nested disclosure for hierarchy that .accordion (flat) and .sidenav (one level) don't cover. Twisty mirrors the accordion chevron; leaves keep alignment. artificer-tree.js ships expand/collapse + arrow-key roving focus (data-tree / ArtificerTree.enhance()).
