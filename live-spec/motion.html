Artificer · Foundations · Motion

motion.

Three durations, one easing. Motion exists to communicate state change, not to delight. Everything collapses to 0ms when prefers-reduced-motion: reduce.

Tokens

TokenValueUse for
--dur-instant80msHover, focus, active state.
--dur-fast160msDefault. Theme switch, toggle, fade-in.
--dur-max300msModal entry, sidebar slide. Ceiling.
--easecubic-bezier(.2,.7,.3,1)Single curve. Decisive in, soft out.

Patterns

01 · State change (160ms)

Hover, focus, theme toggle. Use the default --dur-fast.

02 · Continuous translation

For loading bars, scrubbers. Linear easing OK here; default ease for everything else.

animation: shift 1.6s var(--ease) infinite alternate

03 · Attention pulse (urgent only)

Reserved for blocking errors. Slow (1.6s), low contrast, suppressed under reduced-motion. Apply .pulse.

Build failed

04 · Skeleton shimmer

For wait states > 1s. Subtle horizontal sweep at 1.4s. See states.html.

05 · Modal entry

Slide-up 8px + fade, 160ms. Already wired into .modal; see overlay.html.

Rules

  1. 300ms is the ceiling. Anything longer feels broken.
  2. One easing. Don't invent cubic-beziers. Use --ease.
  3. No parallax, auto-play, or looping decoration.
  4. Honor reduced-motion. Already wired — just don't undo it.
  5. Animate state, not arrival. Don't animate things appearing on page load.
/* Default state-change transition */
transition: background var(--dur-fast) var(--ease);

/* Reduced-motion is automatic via the CSS:
   :root { --dur-instant: 0ms; --dur-fast: 0ms; --dur-max: 0ms; }
   …so transition: ... var(--dur-fast) ... becomes 0ms. */
