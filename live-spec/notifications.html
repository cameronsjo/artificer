02 Stack rules

  • 3 visible max. Overflow → count badge ("+4 more").
  • Oldest auto-dismiss first (info and background tiers only).
  • Pause timers on hover/focus. Don't punish the user for reading slowly.
  • Notification history so missed items are recoverable.
  • Never role="alert" for non-urgent messages.
  • One primary action per toast. Secondary is "dismiss."

The guiding rule: if the user wouldn't take an action, don't show a toast. Badge it silently and move on.
