02 Stack rules

  • 3 visible max. Overflow → count badge ("+4 more").
  • Oldest auto-dismiss first (info tier only — background never enters the stack).
  • Pause timers on hover/focus. Don't punish the user for reading slowly.
  • Notification history so missed items are recoverable.
  • Never role="alert" for non-urgent messages.
  • One primary action per toast. Secondary is "dismiss."

The guiding rule: if the user wouldn't take an action, don't show a toast. Badge it silently and move on.

03 Toast region — live demo

The .toast-region is the fixed placement layer (bottom-right, --z-toast); a toast IS a .notif mounted in it. ARIA is set at insert time — CSS cannot set roles: urgent → role="alert", attention/info → role="status", background → no role (the silent badge never enters the region). Info auto-dismisses after 5s; the timer pauses on hover/focus.
