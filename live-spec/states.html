Artificer · Patterns · States

states.

Empty, loading, error. The three states that make a UI feel finished instead of unfinished. Most apps ship without them; ours doesn't get to.

Loading — by duration

Pick the right tool for how long the wait will actually be.

< 100ms
Nothing. Don't show a spinner that flashes on screen for 80ms.
100–500ms
Disable the trigger, change its label ("Save" → "Saving…"). No skeleton.
500ms–2s
Skeleton or progress bar. Match the shape of incoming content.
> 2s
Progress bar with concrete copy: "Indexing 1,247 of 8,300 files."
> 10s
Background it. Send a notification when done. Don't make me wait.

Skeleton

For 500ms–2s waits with predictable shape. Use --text, --title, or --block modifiers, or set inline width/height.

<div class="skeleton skeleton--title"></div>
<div class="skeleton skeleton--text"></div>
<div class="skeleton skeleton--block"></div>

Progress

Determinate when you can count. With aria-label for screen readers; aria-valuenow makes the percentage read aloud.

Indexing 1,247 of 8,300 files. 15%

Indeterminate (long wait, nothing to count)

Same role="progressbar" + aria-label, but no aria-valuenow/min/max — the missing value is what marks it indeterminate to assistive tech. Don't copy the determinate shape above. Concrete copy is inseparable: name the operation and the target.

Deploying to us-east-1… 
<div class="progress progress--indeterminate" role="progressbar"
     aria-label="Deploying to us-east-1">  // NO aria-valuenow/min/max
  <div class="progress__bar"></div>
</div>

Empty state

Three jobs: name what's missing, explain why (briefly), provide one action. Mono. No illustrations.

No runs yet.

When a build starts, it'll show up here with logs, duration, and cost. Trigger one with artificer run or push to a watched branch.

Read the docs 
<div class="empty-state">
  <p class="empty-state__title">No runs yet.</p>
  <p class="empty-state__body">When a build starts…</p>
  <button class="btn btn--primary">Start a run</button>
</div>

Error state

Three rules: say what happened, say what to do, offer one action. Inline > toast for state-bearing errors.

Inline (recoverable)

Couldn't reach the registry.

We tried 3 times. Your network is fine; it's on our side. Drafts are saved locally.

Full-screen (blocking)

Build failed at step 04 — typecheck.

3 errors in src/runner.ts. The full log is preserved; nothing else was deployed.

// src/runner.ts:42
error TS2345: Argument of type 'string | undefined'
              is not assignable to parameter of type 'string'.
