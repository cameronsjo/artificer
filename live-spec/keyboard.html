Artificer/Keyboard

Keyboard.

Artificer is keyboard-first: every command reachable without the mouse, the same gesture meaning the same thing everywhere. This is the canonical keymap — the muscle memory the whole system shares.

01 The canonical keymap

Every Artificer UI adopts these. ⌘ K opens the command palette — never rebind it to a command; the palette is how you reach commands. On macOS the modifier is ⌘; see platform modifiers for Linux/Windows.

ActionKeysNotes
Open command palette ⌘K Type to filter commands and files. The single entry point to everything. Editor / IDE targets also accept ⌘⇧P for VS Code muscle memory.
Search / filter in view / Focuses the in-view search or filter field. Esc clears and blurs.
Confirm / submit ↵ From any single-line input.
Submit multi-line ⌘↵ Multi-line forms and commit messages — see form rule 7.
Cancel / close / dismiss Esc Closes the modal, palette, or popover and returns focus to the trigger.
Toggle theme ⌘⇧L Dark ⇄ cream.
Navigate a list / palette ↑↓then↵ Arrow keys move, Enter activates. Never mouse-only.
Switch tab / pane ⌘1…⌘9 Where numbered tabs or panes exist.

Display combos with inline <kbd> — one element per key, no bespoke styling. The kbd / .kbd rule in artificer.css already themes them.

02 Cross-app convention

The same intent earns the same gesture across Cameron's themed apps, so muscle memory carries between them. This table is the standard — the actual keybind configs live in dotfiles (chezmoi), not here. Where an app's model can't honor a gesture (terminal emulators have no command palette; multiplexers route through a prefix), the divergence is documented, not papered over.

Prefix-layer apps (tmux, prefix Ctrl+Space) and pure terminal emulators (Ghostty) can't host a global ⌘ K palette — that's a property of the app, not a violation. The convention only binds where the app can honor it; everything else is recorded so the gap is visible.

03 Platform modifiers

The keymap is written for macOS. On Linux and Windows, swap the modifier — the gesture stays identical, only the key changes.

So ⌘K on macOS is CtrlK elsewhere. Render the macOS glyphs in docs; map at the binding layer per platform.
