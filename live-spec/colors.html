04 The rules that keep triage working

Rule 01

Max 2 semantic colors visible at once. If gold + rose + vermillion all appear together, visual priority collapses and the brain checks out. Purple is brand, not semantic — it doesn't count against the cap.

Rule 02

Greyscale is the default state. Color is reserved for meaning. Decorative color is banned. If you can't name what a color means on a page, delete it.

Rule 03

No pure black. #1D1F21 is the darkest value in the system. #000 reads as a hole on Ghostty grey — it's visual noise.

Rule 04

Color meaning is consistent across screens. Gold always means interactive. Rose always means attention. Vermillion always means error. No exceptions for aesthetics.

05 Squint test

Squint at these two panes. The active one must be instantly obvious from peripheral vision. If you have to compare to tell, contrast is too low.

Active pane agents/writer.md Full brightness · accent border · 100% saturation.
Inactive pane agents/editor.md 55% opacity · desaturated · darker ground.
