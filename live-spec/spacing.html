spacing & depth.

An 8px base grid, with a 4px half-step. Generous padding — content should never feel cramped. If it does, there's too much content.

03 Depth — tonal, not shadowed

Base · --bg #292C33
Raised · --bg-raised #313540
Overlay · --bg-overlay #3C4150 · shadow permitted
Inactive · --bg-inactive #1D1F21

Depth through tonal layers. Shadows are banned except on overlays (modals, palette, dropdowns), where a subtle 0 4px 12px rgba(0,0,0,.35) is permitted.

04 Density caps

AuDHD working memory ceilings. Blow past these and the UI becomes noise.

  • Command palette: 5–7 items visible. Frequent/recent first. Type to filter.
  • Sidebar items: 8–10 max. Active item pinned to view.
  • Notification stack: 3 visible. Count badge for overflow.
  • Dropdown / menu: 7 max before grouping with labeled dividers.
  • Any list before "Show more": 5 items. Collapsed by default.
  • Form fields per step: 3–5. Multi-step wizard for anything longer.
  • Top-level nav: 5–6. Beyond that, add search.

05 Progressive disclosure

LEVEL 01 Visible by default Active item, current state, primary action. What the user came here to do.
LEVEL 02 One keystroke away Related options, recent history, secondary actions. Revealed on demand.
LEVEL 03 Intentional search Settings, rare features, full logs. Only found by going looking.

06 Motion

  • --dur-instant · 80ms — micro state changes (hover color).
  • --dur-fast · 160ms — most transitions. The default.
  • --dur-max · 300ms — ceiling. If the user notices, it's too slow.
  • Ease: cubic-bezier(0.2, 0.7, 0.3, 1) — quick out, calm in.
  • Honor prefers-reduced-motion. Durations collapse to 0. No exceptions.
