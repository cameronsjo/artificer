Foundations · Icons

icons.

A small, hand-tuned set rooted in Lucide, keyed by Lucide's canonical names. 16px viewBox, 1.5 stroke, color via currentColor. Used sparingly — at most one per UI row.

Usage

Drop a placeholder anywhere in the DOM. The hydrator replaces it on load.

<script src="artificer-icons.js" defer></script>

<!-- in body -->
<i data-icon="search"></i>
<i data-icon="check" data-icon-size="20"></i>
<i data-icon="triangle-alert" data-icon-stroke="2"></i>

Or build programmatically: ArtificerIcons.build('search') returns an SVGElement.

Names are Lucide-canonical; legacy names (close, chevron-r, edit, trash, alert, spinner, terminal, logout, …) keep working as aliases. theme is the one Artificer-custom name. ArtificerIcons.list() reports canonical names only. An unknown name renders a dashed placeholder box (and a console warning) instead of a silent blank.

Beyond the set

The set is deliberately small — it grows by curation, not accretion. When an app genuinely needs a glyph that isn't here, use Lucide directly (e.g. lucide-react, or a static SVG export) at size 16, stroke 1.5 so it families with the tuned set — and file the name upstream so it can be ruled into the canon or closed. An unknown data-icon name renders a dashed placeholder box, never a silent blank.

Rules

  1. One icon per row. Two competing glyphs is one too many.
  2. Always paired with a text label in primary navigation. Icon-only is reserved for tight chrome (close, expand).
  3. Inherit color via currentColor. Never hardcode a hex.
  4. Don't tint semantically. Color comes from the parent (e.g. .btn--destructive), not the icon.
