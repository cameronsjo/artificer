01 What this is for

Artificer is designed for one specific user — someone who scans instead of reads, holds 3–4 items in working memory, and pays amplified cognitive cost at every decision. Everything here optimizes for that brain.

If you're picking a pretty theme for a marketing site, wrong system. If you're building tools — command surfaces, dashboards, editors, agent interfaces — stay.

The core bet

A UI that does the triage so the brain doesn't have to. Ghostty dark grey as the foundation, burnished gold as the one accent that means "act here." Color reserved exclusively for meaning.

02 The Jazz Age palette, explained

The accents borrow from 1920s–50s screen-print poster work: burnished gold (glamour, brass, the thing that glitters), vermillion (lipstick, danger, neon), dusty rose (silk, blush, the softer counterweight), and steel blue (rivets, denim, the honest middle). Gold is the primary — the only color that means you can act on this.

Every accent has two forms: a text-safe value (tuned for AAA contrast on the current background) and a fill value (the original saturated hex, used as button/badge background where legibility lives in the on-color text). Both themes map to the same semantic tokens.

03 Three principles

01 · SCAN Anchors, not prose Bold 3–5 anchor words per paragraph. A page scanned only for bolded words should still make sense.
02 · TRIAGE Greyscale by default Max 2 semantic colors on screen at once. Color means something. Decorative color is banned.
03 · RESTRAINT Max 5–7 per list Palette, sidebar, dropdown — everything capped. Beyond the cap: progressive disclosure or type-to-filter.

05 The ten rules

When generating anything with Artificer, hold these in mind. Not style preferences — they are the system.

  • Read the spec first. Tokens and semantic rules, not arbitrary values.
  • Limit visible items. No list exceeds 7 without progressive disclosure. Default to 5.
  • One primary CTA per screen. Secondary actions are visually demoted.
  • Bold anchor words. 3–5 per paragraph. Primary reading mechanism.
  • Chunk in threes. Groups of 3 match ADHD working memory.
  • No decorative elements. If removing it changes nothing, remove it.
  • Tier notifications by action-required. Badge silently if no action needed.
  • Active state is dramatic. Inactive panes drop 50–60% opacity. Not subtle.
  • Never rely on memory. Persistent labels, breadcrumbs, progress indicators.
  • Pass the squint test. If you can't tell what's active, contrast is too low.

06 Do & Don't

Do

  • Use gold only for interactive elements
  • Maintain WCAG AAA for body text (7:1)
  • Bold 3–5 anchor words per paragraph
  • Auto-save continuously without asking
  • Keyboard-first, mouse-secondary
  • Summaries first (inverted pyramid)
  • Chunk into groups of 3
  • Honor prefers-reduced-motion

Don't

  • Show more than 2 semantic colors at once
  • Use pure black (#000) anywhere
  • Justify text — creates rivers
  • Use placeholder-only form labels
  • Auto-play, loop, or parallax
  • Exceed 300ms transitions
  • Mix rounded and sharp corners in one view
  • Use sarcasm, metaphor, or figurative copy

07 Voice

Artificer's copy is literal, direct, and lightly deadpan. Autism demands clarity — a sarcastic error is a confusing error. A metaphor-heavy tooltip is a broken tooltip.

The wit lives in the restraint. A palette that shows the exact five things you need is funnier than any pun written into it.

Copy checklist

Is it literal? Would the user know what to do from the first seven words? Does it name the thing instead of gesturing at it? If yes: ship. If no: rewrite.
