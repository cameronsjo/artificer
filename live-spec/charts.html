charts.

Artificer doesn't ship a chart library — it ships tokens, an aesthetic, and templates. Any library that lets you set series colors, axis colors, and grid colors can render in the Artificer voice. The SVG examples below double as copy-paste templates if you're rendering by hand.

Color rules

Three modes, one rule for each. Don't blend modes in the same chart.

1 · Grayscale + accent — hierarchy mode

Use when one series is the answer and the others are context. Series 1 is the accent; the rest are gray.

2 · Categorical 5 — peer mode

Use when series are peers (services, regions, products). Cap at 5 — beyond that, regroup.

3 · Sequential ramp — quantitative encoding

Use when color encodes a number (heatmap, choropleth, density). Single hue, 5 stops.

Bars / meters

The liftable horizontal bar — .bar (row) wraps an optional label and a .bar__track holding a .bar__fill. Width is set inline; the fill background is any semantic token — --accent-fill by default, a --series-* for categorical, a --diverge-* for valenced. Two gotchas the primitive bakes out: the fill sets display:block; height:100% so it never collapses to zero (a bare styleless fill is invisible), and when inlining tokens into a single-file artifact the *-fill tokens must be in the copied set.

The no-pie rule

Pie/donut charts are permitted only at n ≤ 3 slices, and only when "parts of a whole" is the entire point. For everything else — including parts-of-whole with 4+ slices — use a bar chart.

Rules

  1. Bar before line before pie before anything else. Nine times in ten, the chart you're reaching for should be a bar chart.
  2. No pie/donut at n > 3. Bar chart instead. The exception is a single binary "used / remaining" — fine as a donut.
  3. Cap series at 5. Beyond that, regroup, facet, or split the chart.
  4. No legend when there's one series. The chart title is the legend.
  5. Annotations live in the plot when a chart needs to make a point — not in the legend, not in body copy.
  6. Tabular numerals everywhere a number appears. Tooltips, axis labels, chart values, sparkline cells. Already wired via --font-mono; just don't break it.
  7. Color encodes one thing. Don't overload — series identity OR magnitude OR sign, never two at once.
  8. Two gridlines max. Baseline + one mid. More than that is graph paper, not a chart.
  9. Y-axis baseline at zero for bars. Truncated baselines are dishonest. Lines may use a fitted Y range.
  10. Sparklines have no axes. If you find yourself wanting axis labels, you wanted a chart, not a sparkline.
  11. Honor reduced-motion. Don't animate chart entry by default; the data is the point.

Library mappings

If you're not drawing SVG by hand, forward Artificer tokens into your chart library's theme config.

ECharts

{
  color: [
    getComputedStyle(document.documentElement).getPropertyValue('--series-1'),
    getComputedStyle(document.documentElement).getPropertyValue('--series-2'),
    /* …5 total */
  ],
  textStyle: { fontFamily: 'JetBrains Mono', color: 'var(--fg-secondary)' },
  grid:  { borderColor: 'var(--chart-grid)', show: false },
  xAxis: { axisLine: { lineStyle: { color: 'var(--chart-axis)' } } },
  yAxis: { splitLine: { lineStyle: { color: 'var(--chart-grid)' } } },
}

Recharts (React)

<LineChart>
  <CartesianGrid stroke="var(--chart-grid)" vertical={false} />
  <XAxis stroke="var(--chart-axis)" tick={{ fontFamily: 'var(--font-mono)' }} />
  <YAxis stroke="var(--chart-axis)" />
  <Line dataKey="v" stroke="var(--series-1)" strokeWidth={1.6} dot={false} />
</LineChart>

Observable Plot

Plot.plot({
  style: { background: 'transparent', fontFamily: 'JetBrains Mono', color: 'var(--fg-secondary)' },
  marks: [
    Plot.ruleY([0], { stroke: 'var(--chart-grid-strong)' }),
    Plot.line(data, { x: 't', y: 'v', stroke: 'var(--series-1)', strokeWidth: 1.6 }),
  ],
})
