whimsy.

The one sanctioned exception to "no looping decoration" and "no raw color." A flowing sine-wave rainbow — the feeling of an ultrathink shimmer — reserved for user-defined fun elements and whimsical operations. It is burnished, not neon: the spectrum is generated in oklch at the palette's own chroma, and its hue stops land on Artificer's real brand colors. A rainbow made of the palette, set in motion.

ultrathink

The knobs

Whimsy reads its colors from the live palette and exposes a few custom properties. Override them on any scope to retune locally — no new tokens, no hex.

--whimsy-cChroma. Default 0.115 (palette-muted). Add .whimsy--vivid for 0.21. --whimsy-lLightness. 0.80 dark · 0.52 light (auto, reads on cream). --whimsy-speedOne full hue cycle. Default 7s — calm, not frantic. --whimsy-angleGradient direction across the glyphs. Default 100deg. --whimsy-riseSine-bob amplitude for the wave variant. Default 0.16em. --whimsy-settle-speedGlacial-rest cycle. Default 150s (~2.5 min) — motion you can't catch. --whimsy-gradientThe whole palette, in one knob. .whimsy--brand overrides it with Artificer's tokens; set your own for anything else.
burnished vs vivid

Two palettes

The default is a burnished full spectrum — the "normal RGB" look, kept in-family. .whimsy--brand swaps it for Artificer's real semantic tokens (gold → rose → brand-purple → steel → green), reading the live CSS vars so it tracks light/dark for free.

spectrum brand

Both are just values of one variable. Bring your own palette in a single line: style="--whimsy-gradient: linear-gradient(100deg, var(--success), var(--accent), var(--success))"

Patterns

01 · Flowing wordmark

The signature. Apply .whimsy to a short word set large + bold. Use for the brand wordmark, a feature name, a hero moment.

Artificer

02 · Sine wave (per-character bob)

Add data-whimsy="wave" — Whimsy.hydrate() splits the text into bobbing characters so the wave travels. Degrades to a flat gradient without JS.

ultracode

03 · Rainbow rule

A sine wave the spectrum flows through. A flourish for section breaks and celebration moments — not a default divider. .whimsy-rule (or --sm).

04 · Trigger word (the "ultrathink" gesture)

Type ultrathink or ultracode below. Whimsy.watch() ignites the target the moment the word appears, and clears it when it's gone.

Mode: standard

05 · Celebrate (whimsical operation)

One-shot whimsy for an operation that just succeeded — then it clears itself. Whimsy.celebrate(el). A receipt with a little joy, not a parade.

deploy complete

06 · Settle (whimsy that comes to rest)

Long-lived whimsy shouldn't loop forever. Whimsy.run(el, {loops, settle}) flows for N hue-cycles then rests — static (motion off, the gradient freezes on a held slice) or glacial (one hue drift over --whimsy-settle-speed ≈ 2.5 min, bob off). The full playground above is live; this is the one-shot. Per-effect toggles ship too: .whimsy--no-flow, .whimsy--no-bob, and the opt-in .whimsy--glow.

settling…

07 · Silver — a metal sheen, quiet enough for headers

The most restrained whimsy in the box. .whimsy--silver drops the rainbow for a near-neutral sheen: silver/grey on dark, warm graphite on cream. Text must contrast its surface, so light mode inverts to ink-with-a-bone-undertone — not literal bone-on-bone. It defaults slow (16s) so it reads as a sheen, not a sweep; add .whimsy--no-flow for a still metallic fill — the recommended header default, zero motion. Try the Silver palette in the playground above.

Slow sheen · 16s drift · one moving header per view, max Wiring

A word on making it the header default: a static silver fill on every header is fine — it's just a refined text color. But an animated sheen on every header breaks doctrine #2 ("whimsy everywhere is wallpaper"). If you want motion, reserve it for one hero header, or trigger the sheen on :hover and leave headers still at rest.

08 · Focus ring (the one sanctioned interactive whimsy)

A burnished ring that circles a control on hover or focus — delight layered over the standard focus outline, never replacing it. The system :focus-visible outline still does the WCAG work; this spins on top. .whimsy-focus on the control. This is the only whimsy that touches an interactive element, and only on explicit request (§ Whimsy, doctrine #3). One per view; under reduced-motion the ring holds still but stays visible.

Hover a button — or Tab to it — to see the ring. (Show the ring forces it on for touch.)

The doctrine

  1. Opt-in only. Never on page chrome, nav, or anything automatic. Whimsy is something a person chose to light up.
  2. One whimsy moment per view. Like the one-primary-CTA rule. Whimsy that's everywhere is just wallpaper.
  3. Never on load-bearing UI. No whimsy on errors, destructive actions, status, or data. It decorates delight, never function. One sanctioned exception: the .whimsy-focus ring (pattern 08), which augments the standard focus outline rather than replacing it — the outline still carries the a11y signal. Reach for it only on explicit request.
  4. Burnished by default. It's tuned to the palette. Reach for .whimsy--vivid consciously, not by reflex.
  5. Display + bold only. Gradient text drops contrast — keep it large. Never set body copy in whimsy.
  6. Reduced-motion is sacred. The flow stops; the burnished gradient stays. Already wired — don't undo it.
  7. Whimsy rests. Anything long-lived settles after a few loops — to a static gradient or a glacial drift. A rainbow that never stops is just wallpaper; the joy is in the arrival and the coming-to-rest.

Wiring

<!-- after artificer.css -->
<link rel="stylesheet" href="artificer-whimsy.css">
<script src="artificer-whimsy.js" defer></script>

/* signature wordmark */
<span class="whimsy">ultrathink</span>

/* sine wave — hydrate() splits it into bobbing chars */
<span data-whimsy="wave">ultracode</span>

/* the ultrathink gesture + a whimsical operation */
Whimsy.watch(input, { triggers: ["ultrathink"] });
Whimsy.celebrate(el);  // one-shot, auto-clears

/* flow, then come to rest — for long "thinking" states */
Whimsy.run(el, { loops: 4, settle: "glacial" });

/* toggle any one layer off: */
<span class="whimsy whimsy--no-bob">flow, no bob</span>

/* silver header — still metallic fill, no motion */
<h2 class="whimsy whimsy--silver whimsy--no-flow">Wiring</h2>
