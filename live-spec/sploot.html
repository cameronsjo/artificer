sploot.

The system's critter: a Pembroke corgi, named for the flat-out, back-legs-behind lounge corgis are known for. Drawn as real text — quadrant block glyphs, two by two pixels per character — so it renders in JetBrains Mono and pastes into a terminal intact. Gold like the wordmark's stop, single-tone, static. Every Sploot here is artificer-sploot.js hydrating a data-sploot host. Hover one: it hops once.

Use it

<!-- .sploot lives in artificer.css; the module draws -->
<script src="artificer-sploot.js" defer></script>

<span data-sploot="sleep"></span>
<span class="sploot--sm" data-sploot="stand"></span>
<span data-sploot="mini" data-sploot-decorative></span>

/* static build: no DOM, no client JS */
import '@cameronsjo/artificer/sploot.js';
const html = ArtificerSploot.markup('sniff');

Hydrates on its own, and observe() picks up SPA inserts. Hosts get role="img" and a pose description; data-sploot-decorative hides one that sits beside a label saying the same thing.

Rules

  1. One Sploot per view. It's the brand's face, not wallpaper.
  2. Never on load-bearing UI — errors, status, data, destructive actions. Empty states and not-found pages are fine; the copy stays literal and Sploot carries the mood.
  3. Always --accent, single-tone. Costumes (helmet, scarf) are overlay layers in existing tokens, never a recolor.
  4. Static. The hover hop is the only motion — a state change on --dur-max, off under reduced motion.
  5. The four sizes only. The size arithmetic is what keeps the glyphs seamless.
  6. Poses come from the grids in artificer-sploot.js. A new pose is a new grid, not a hand-drawn variant.

Drawing a new pose

A pose is an array of strings, # for a pixel. Pixels render tall — about 0.3 × 0.65 em — so a grid reads twice as wide as it looks in source. Keep the silhouette's five cues: a body about three times longer than tall, ears as wide-based triangles, a pointed snout, one-row legs, a rounded rump. Front and rear views read as a cat or a fox; side-on is Sploot. Check a draft against famous sprites before it ships — antennae plus square eyes read as someone else's alien.

The block glyphs come from a unicode-range subset of JetBrains Mono (U+2500–25FF) that artificer.css loads with the family — see FONTS.md.
