overlays.

Six z-index rungs, two component shapes, one focus-trap helper. Anything that floats over content lives here.

Z-index scale

No improvising. Pick one rung. The full ladder, low to high:

TokenValueUse for
--z-base1In-flow content. Default.
--z-raised10Sticky elements, dropdown triggers.
--z-overlay100Sidebars, theme toggle, sticky page header.
--z-popover1000Tooltips, popovers, dropdown menus.
--z-modal2000Modal dialogs (scrim + content).
--z-toast3000Always-on-top notifications, skip-link.

Modal

Centered card on a scrim. Auto focus-traps via artificer-focus.js. Esc closes; clicking the scrim closes; focus returns to the trigger.

<div class="scrim" role="presentation">
  <div class="modal" role="dialog" aria-modal="true" aria-labelledby="t">
    <h2 id="t" class="modal__title">Title</h2>
    <p class="modal__body">Body…</p>
    <div class="modal__footer">
      <button class="btn btn--ghost">Cancel</button>
      <button class="btn btn--primary">Confirm</button>
    </div>
  </div>
</div>
// JS
const trap = ArtificerFocus.trap(modal, { onEscape: close });

Popover & tooltip

Smaller, anchored. Tooltip = label-only (≤ 6 words). Popover = body content. Both use --z-popover.

Modal size variants

Three width tiers for dialogs vs. content viewers. All compose with .scrim and the standard focus-trap pattern.

ClassMax widthUse for
.modal480pxConfirmation dialogs, short forms.
.modal--lg720pxLonger forms, multi-step flows.
.modal--xlmin(96vw, 1100px)Content viewers — diagrams, wide tables, previews.
.modal--full100vw · no radiusFull-screen on mobile. Pair with .scrim--flush (removes scrim padding).

Focus-trap rules

  1. Trap focus while a modal is open — Tab cycles inside.
  2. Esc closes. Always. No exceptions.
  3. Restore focus to the trigger element on close.
  4. Use aria-modal="true" and role="dialog" on the modal box.
  5. Label every dialog via aria-labelledby pointing to the title id.
