layout primitives.

Five composable utilities. Stack for vertical rhythm, cluster for horizontal flow, grid-auto for responsive cards, container for max-widths, page-shell for sticky-header layouts.

.stack — vertical rhythm

Direct children get even vertical gaps. Override --gap or use .stack--{xs|sm|md|lg|xl|2xl}.

child 1
child 2
child 3
<div class="stack stack--sm">
  <div>…</div>
  <div>…</div>
</div>

.cluster — horizontal flow that wraps

For toolbars, chip rows, button groups. Wraps gracefully on small screens.

tag-1tag-2tag-3tag-4
<div class="cluster">…</div>

Modifiers: .cluster--between (justify-content: space-between), .cluster--end, .cluster--sm, .cluster--lg.

.grid-auto — responsive equal columns

Set --min to control the breakpoint (default 240px). Cards collapse to single column when no two fit.

A
B
C
D
<div class="grid-auto" style="--min: 240px">…</div>

Or fixed: .grid-2, .grid-3 (collapse to 1-col below 640px).

.container — max-width wrappers

Classmax-widthUse for
.container--sm560pxLogin forms, dialogs as pages, single-column reading.
.container--md820pxDefault for docs, settings, content pages.
.container--lg1120pxDashboards, tables, multi-column layouts.

.page-shell — sticky masthead

Two-row grid: header sticks, main scrolls. Header gets z-index: var(--z-overlay) automatically.

<body class="page-shell">
  <header>…</header>
  <main>…</main>
</body>

Composition recipe

Most pages: page-shell > container--md > stack. That's it. Resist nesting deeper without a reason.
