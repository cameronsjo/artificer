Cell glyphs

Dense comparison grids reach for emoji (✅ ⚠️ ❌) — but emoji are OS-rendered: they ignore the theme and read loud in a grid. The .glyph set is the anti-emoji — real text the author types, tinted by a semantic token, so it tracks dark/cream. Four states: --success ✓ yes, --muted ✗ no (recedes, steel-blue), --attention ~ partial, --na – not applicable. Each glyph is a graphical object (WCAG 2.2 SC 1.4.11), so it carries an aria-label — meaning never rests on the mark alone.

Rules

  1. Numbers use font-variant-numeric: tabular-nums. Always. Add .num or set on parent.
  2. Right-align numeric columns, left-align text. Don't center either.
  3. Include units in the value, scaled down (smaller, secondary color). Don't put units in the label.
  4. Cap stat rows at 4. More than 4 means people stop reading.
  5. Empty cells get — (em dash), not "N/A" or 0.
  6. Status uses badge + dot, not color alone — color-blind users.
  7. Dense grids use cell glyphs, not emoji — .glyph--{success|muted|attention|na} tints ✓✗~– with a theme token. Each is graphical: pair it with aria-label, never the mark alone. Sparse, labeled status stays .badge + .dot.
