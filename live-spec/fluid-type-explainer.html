The tradeoff

Fixed (keep)

  • Predictable. 28px is 28px — in a dense table header, a modal, a phone, a 4K monitor.
  • On-identity. Artificer sets hierarchy by weight + color, not size. Size stays constant on purpose.
  • Cost: on a very wide screen a hero title can feel a touch small; on a phone it's fine.

Fluid (the option)

  • Presence. A title grows on big screens (more impact) and shrinks on phones (less cramped).
  • Cost: the exact size becomes a variable — harder to reason about, and it leans on size as hierarchy, which the system deliberately doesn't.
  • Cost: on tool chrome / data it adds jitter for no reading benefit.
Proposed ruling

Keep the fixed scale for everything operational (tools, data, chrome, the core --t-* tokens). Allow fluid only on editorial hero titles — long-form reading surfaces (.surface-editorial), where reading, not operating, makes "presence on a big screen" worth the unpredictability. Written as a carve when the editorial surface lands (v0.9.0 PR B).
